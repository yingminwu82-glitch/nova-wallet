# NOVA WALLET — Phase 1

A responsive, interactive product launch concept for a premium smart wallet. Hardware, Bluetooth, location and buzzer behaviors are demonstrations only; no physical device or GPS is connected.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev` and open the URL shown by Vite.
4. Run `npm run build` to create a production build in `dist/`.

The interactive wallet uses React Three Fiber with procedural geometry and studio lighting. Drag to orbit, scroll to zoom, and use view controls. Simulated activity history is saved in browser Local Storage.
